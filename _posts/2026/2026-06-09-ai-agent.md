## 1.Memory

LLM 的记忆有限，需要开发者做 Memory 管理

## 2.Tool

LLM 需要调用的工具，需要开发者开发好 Tool 交给它。
用于各种需要给 LLM 扩展能力的场景

## 3.RAG

LLM 没办法对不知道的私密文档做解答，需要扩展 RAG 知识库查询能力

## 4.LLM

LLM 自身有规划和推理的能力

## LangChain 框架

用来开发单个 Agent，每个 Agent 做一件事

## LangGraph

基于 LangChain 封装的，用于多 Agent 交互的框架。

## Agent

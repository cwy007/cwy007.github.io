## 1.MCP

ai agent 是 MCP 客户端，可以通过 MCP 协议调用各种 MCP server，实现跨进程的工具调用

![MCP](image/MCP.png)

- 跨本地的进程调用，用 stdio
- 跨远程的进程调用，用 http

MCP 是由 Anthropic 公司发起并开发的，2025年12月交给了 Linux 基金会维护。

是中立于任何模型的行业通用协议。

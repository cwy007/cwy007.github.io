# 实现展开和折叠效果

原生 Markdown 语法中**没有**专门用于“展开/折叠”的语法标记。

但是，因为 Markdown 天然支持直接兼容 HTML 标签，所以你完全可以使用 HTML5 的 **`<details>`** 和 **`<summary>`** 标签来实现展开/折叠（手风琴）效果。这个方法在 GitHub、你现在使用的 Jekyll 博客系统以及大部分主流 Markdown 编辑器中都是完全支持的。

## 使用方法如下

```html
<details>
  <summary>点击这里展开/折叠内容</summary>

  这里是你想要折叠的内容。

  **注意：** 如果你打算在折叠内容里面继续使用 Markdown 语法（比如加粗、列表、代码块等），**`<summary>` 标签下面一定要空一行**，否则 Markdown 解析器可能无法正确渲染里面的 Markdown 语法。

  - 列表项 1
  - 列表项 2

</details>
```

## 标签解释

* `<details>`：相当于一个折叠块的容器。如果你想它**默认是展开**的，可以写成 `<details open>`。
* `<summary>`：这是折叠块的标题（即用户看到并点击的那一行文本）。
* 在 `<summary>` 闭合标签之后就是被折叠的详细内容。

在你的环境中（你的代码库 `cwy007.github.io` 是一个 Jekyll 博客），由于 Jekyll 默认使用的是 Kramdown 解析器，遇到 HTML 标签内部的文本时，它会默认停止解析其中的 Markdown 语法。

要让它强制识别并渲染 `details` 标签里的 Markdown，你需要做**两件事**：

### 1. 添加 `markdown="1"` 属性
你需要给 `<details>` 标签加上 `markdown="1"` 的属性，以此告诉解析器“请把我里面的内容当做 Markdown 来渲染”。

### 2. 必须留出空行
在 `<summary>` 闭合之后，**必须要有至少一个空行**，才能开始写你的 Markdown 内容。在内容结束和 `</details>` 之间，最好也留一个空行。

### 完美生效的写法模板：

```html
<details markdown="1">
<summary>点击展开查看代码和高亮文本</summary>

（👈 这里必须要有一行空行）
这里可以正常使用你的 **Markdown** 语法。

- 列表项 1
- 列表项 2

```javascript
// 甚至代码块也能完美渲染
const a = "Hello Markdown";
```
（👈 结束前也建议留一行空行）
</details>
```

你直接把这个模板复制到你的 `2026-04-26-nest-aop.md` 文件里测试一下即可。这是在 Jekyll/Kramdown 环境下彻底解决这个问题的标准方案。你直接把这个模板复制到你的 `2026-04-26-nest-aop.md` 文件里测试一下即可。这是在 Jekyll/Kramdown 环境下彻底解决这个问题的标准方案。

vscode 在 md 文件中没有识别 detials 开始和结束标签，无法折叠/展开 details 中的内容

这是一个在 VS Code 中编写 Markdown 时常见的问题。

因为 VS Code 原生的 Markdown 编辑器折叠功能是基于 **Markdown 的标题层级（如 `#`、`##`）** 和 **缩进** 来计算折叠区域的，它并不能原生识别甚至解析复杂的 HTML 标签（如 `<details>`）作为编辑器里的折叠块。

要在 VS Code **编辑器内部**（左侧行号旁边）实现对这段内容的强制折叠，你可以使用 VS Code 自带的 **自定义折叠区域（Region Folding）** 注释语法。

### 解决方法：使用 `region` 注释

在你的 `<details>` 标签前后，加上 `<!-- #region -->` 和 `<!-- #endregion -->` 注释：

```html
<!-- #region 展开/折叠块 -->
<details markdown="1">
<summary>点击展开查看代码和高亮文本</summary>

这里可以正常使用你的 **Markdown** 语法。

- 列表项 1
- 列表项 2

</details>
<!-- #endregion -->
```

**效果：**

1. 加上这两行注释后，你的 VS Code 左侧行号（`<!-- #region -->` 这一行）就会出现一个小箭头 `v`，点击它**就可以直接在编辑器里折叠这整块代码**了。
2. 你还可以在 `#region` 后面加上说明文字（如例子中的 `展开/折叠块`），折叠后会在编辑器中显示这个说明，非常方便。
3. 作为 HTML 注释，`<!-- #region -->` 渲染到最终的网页上时也是不可见的，完全不影响你的博客展示。

在 VS Code 中如果没有出现折叠的小箭头（`v`），通常有以下几个原因及对应的解决办法，你可以逐一排查：

### 1. 尝试精简注释（去除非英文字符）
有时候某些插件或 VS Code 版本对带有中文或特殊空格的 region 匹配不够好。请试着删掉后面的描述，只保留最纯粹的标记，并且**前后保持空行**：

```markdown
<!-- #region -->

<details markdown="1">
...里面是内容...
</details>

<!-- #endregion -->
```
